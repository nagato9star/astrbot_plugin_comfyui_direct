1. 工作流图

    在 ComfyUI 菜单里选 Save (API Format)，把 JSON 导进来。普通 Save 的文件可能对不上。

    2. 配方套装

      先导入工作流，再到插件配置的「模型家族与工作流」中添加家族并选择这张图。重载插件后，在这里确认共享槽位并保存配方参数。

      3. 这张工作流的共享槽位

      槽位跟随模型家族所选的工作流，同一工作流的所有配方共用。保存任意配方时会一并保存这份映射。

      更多格子（画师 / 负向 / 触发词，没有就不用管）
